//***********************************************
// キーマウ操作
//***********************************************
画面遷移      → [ マウスの左クリック(タイトルのみ),Enterキー ]
移動          → [ W/A/S/D ]
ポーズ        → [ Pキーで起動 ]
ポーズ選択    → [ W/S or ↑/↓ で選択、Enterで遷移 ]
タスクインタラクト  → [ Fキー ]
サボりインタラクト  → [ Fキー ]

//***********************************************
// ゲームパッド操作
//***********************************************
画面遷移      → [ Startボタン or Aボタン ]
移動          → [ 左スティック / 十字キー ]
ポーズ        → [ Startボタンで起動 ]
ポーズ選択    → [ ↑/↓ で選択、Aで遷移 ]
タスクインタラクト  → [ Aボタン ]
サボりインタラクト  → [ Aボタン ]
