//------------------------------------------------
// 操作方法
//------------------------------------------------
本ゲームではタイトル画面で「キーマウ」、「ゲームパッド」操作の選択を分けております。

//-----------------------------
// ①キーボード操作
//-----------------------------
移動						[ W/A/S/D ]
インタラクト				[ F ]
サボり起動					[ F ]
外タスク起動				[ F ]
タスク操作					[ 画面内の指定キー入力 ]
ポーズ						[ P ]
選択入力					[ W/S or ↑/↓キー ]
画面遷移・決定				[ Enterキー or マウス左クリック ]
(チュートリアル)スキップ	[ Spaceキー(トリガー) ]

//-----------------------------
// ②ゲームパッド操作
//-----------------------------
移動						[ Lスティック / 十字キー ]
インタラクト				[ Startボタン ]
サボり起動					[ Startボタン ]
外タスク起動				[ Startボタン ]
タスク操作					[ 画面内の指定キー入力 ]
ポーズ						[ Backボタン ]
選択入力					[ 十字キーの↑/↓ ]
画面遷移・決定				[ Aボタン or Startボタン ]
(チュートリアル)スキップ	[ backボタン ]
